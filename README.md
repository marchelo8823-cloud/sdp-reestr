# Проверка документов испытаний СДП

Открытый сайт проверки отчётов и заключений об испытаниях систем динамического позиционирования.
Независимый эксперт СДП Марченко Е.С.

- `index.html` — страница проверки (по номеру и коду, по QR-коду, по файлу).
- `registry.json` — данные реестра. Обновляется из реестра кнопкой «Выгрузить для сайта».
